🚀 ci-static-container-builder

Your static site, served fast over HTTPS.

✅ It works!

This example page is being served by the ci-static-container-builder Docker image. Replace the contents of example/public/ with your own built static site (React, Vue, Angular, plain HTML, etc.).

🔒 HTTPS (nginx approach)

docker build \
  --build-arg STATIC_FILES_PATH=./my-app/dist \
  -t my-site:latest .

docker run --rm -p 80:80 -p 443:443 my-site:latest

⚡ WebAssembly (Spin/WASM approach)

docker build \
  -f Dockerfile.wasm \
  --build-arg STATIC_FILES_PATH=./my-app/dist \
  -t my-site-wasm:latest .

docker run --rm -p 3000:3000 my-site-wasm:latest

🩺 Health check

The nginx container exposes a lightweight health-check endpoint at GET /health that returns 200 healthy.
